Hiring Operations Dashboard for Elevare Human Solutions

UI/UX Designer & Frontend Developer · Figma, HTML/CSS, JavaScript

Elevare Human Solutions needed a clearer way to track candidates moving through their hiring pipeline. I designed and built a dashboard that brings every stage of the hiring process — sourcing, interviews, offers — into one scannable view.

  1. DiscoverLooked at how their hiring team tracked candidates and where visibility broke down across stages.
  2. DefinePrioritized a clear view of where every candidate sits in the pipeline, so nothing falls through the cracks.
  3. DesignDesigned the full interface in Figma — candidate pipeline view, stage indicators and a consistent visual system for status and progress.
  4. DeliverBuilt the frontend from the Figma design, translating the component system into working HTML, CSS and JavaScript.

PriorityPulse — Task Management Web App

UI/UX Designer & Developer · Final Capstone Project, GoMyCode Software Development Bootcamp · Figma, HTML/CSS, JavaScript/TypeScript

Most people juggle to-dos across notes apps, reminders and their memory. As my final capstone project for the GoMyCode Software Development Bootcamp, I designed and built PriorityPulse, a task-management app to help anyone organize their day-to-day work in one place — deployed and live.

  1. DiscoverLooked at common friction points in everyday task apps — cluttered lists, no clear sense of priority.
  2. DefineFocused the product around one idea: make it obvious what to do next, not just what's on the list.
  3. DesignDesigned the task list, priority states and add/edit flows in Figma, keeping the interface minimal and fast to scan.
  4. DeliverBuilt and shipped the full app — frontend deployed on Vercel, backend/API deployed on Render.

The Reserve — Restaurant & Reservations Site

UI/UX Designer & Frontend Developer · Bootstrap CSS Course Project · HTML, CSS, Bootstrap 5

The Reserve is a restaurant and reservations site I designed and built as a Bootstrap CSS course project, aimed at giving an upscale dining brand a site that feels as considered as the food.

  1. DiscoverLooked at how upscale restaurant sites use typography and imagery to signal quality before a visitor reads a word of copy.
  2. DefineAimed for a warm, editorial feel — a serif and sans pairing that reads elegant rather than corporate.
  3. DesignPaired EB Garamond with Be Vietnam Pro, and laid out the navigation, hero and menu sections using Bootstrap's grid and components.
  4. DeliverBuilt the full responsive site in HTML, CSS and Bootstrap 5.3.3, then deployed it live.

ABOUT

The short version

I started in IT operations and helpdesk work — the kind of job where you learn exactly what frustrates people about software, because they call you about it every day. That's what pulled me toward design.

Since late 2024 I've trained intensively as a UI/UX designer with GoMyCode in Lagos, moving from low-fidelity sketches to polished, interactive Figma prototypes, then bridging those designs into real HTML and CSS so they hold up outside the design file.

I like projects where I own both ends: the user flow and the shipped layout.
